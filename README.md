# Таймер выступлений

> Программное средство для контроля и визуализации регламента публичных выступлений

---

## 📖 О проекте

**Выпускная квалификационная работа (бакалаврская работа)**  
**Тема:** Разработка программного средства для контроля и визуализации регламента публичного выступления

Разработано десктопное приложение «Таймер выступлений» для эффективного контроля времени публичных выступлений, наглядной визуализации временных фаз для выступающего и аудитории, а также автоматизированного сбора и анализа статистики о проведённых мероприятиях.


---

## Ключевые возможности

- **Три режима таймера** − обратный отсчёт, прямой отсчёт и двойной режим
- **Звуковые сигналы** — предупреждение перед окончанием и финальный сигнал
- **Цветовая индикация** — зелёный → жёлтый → красный в зависимости от фазы выступления
- **Автономность** — полная работа без подключения к интернету
- **Компактное окно** — полупрозрачное окно поверх всех приложений для проектора
- **Многоэтапные сценарии** — автоматическое переключение между этапами выступления
- **Интеграция с PowerPoint** — автоматический запуск и переключение этапов по слайдам
- **Статистика и отчёты** — сбор данных, построение графиков, экспорт в PDF, CSV и JSON
- **Горячие клавиши** — быстрое управление таймером без отвлечения от выступления


---

## Технологический стек

**Основное:**
- Python 3.10+
- PyQt6 — графический интерфейс
- SQLite 3 — встраиваемая база данных
- `pygame` — звуковые уведомления
- `pywin32` — интеграция с Microsoft PowerPoint через COM
- `matplotlib`, `seaborn` — визуализация данных
- `numpy` — числовые расчёты
- `reportlab` — генерация PDF-отчётов

## Архитектура приложения

Приложение построено на **адаптированном паттерне MVC** с четырьмя слоями:
<img width="900" height="430" alt="image" src="https://github.com/user-attachments/assets/a7e6f09b-ed8c-47de-8ef9-2b710efa5912" />
*Рисунок 1 — Архитектура программного средства «Таймер выступлений»*


**Слои:**

- **UI Layer (Presentation)** — все визуальные компоненты: главное окно, компактное окно, окна настроек, редактор сценариев и статистики
- **Controller Layer (Business Logic)** — центральный класс `PresentationController`, управляющий жизненным циклом сценария и координацией компонентов
- **Domain / Core Layer** — бизнес-сущности: `TimerEngine`, `PresentationScript`, `PresentationStage`
- **Data / Infrastructure Layer** — работа с SQLite, настройками, PowerPoint и звуком


## Схема базы данных

Приложение использует **SQLite 3** — встраиваемую СУБД, не требующую отдельного сервера. Все данные хранятся в одном файле, что упрощает резервное копирование и делает приложение полностью автономным.

<img width="900" height="451" alt="image" src="https://github.com/user-attachments/assets/c5a7060f-1a54-4fb7-8ecd-b21f1d1c515b" />

*Рисунок 2 — Схема базы данных приложения*

**Основные таблицы:**

- **`scripts`** — сценарии выступлений (название, дата создания)
- **`script_stages`** — этапы каждого сценария (название, длительность, порядок)
- **`presentations`** — сводная статистика по каждому выступлению (время, режим, превышение регламента, паузы)
- **`presentation_stages`** — детальная статистика по каждому этапу выступления
- **`user_settings`** — пользовательские настройки приложения (цвета, звук, прозрачность, привязки)
- **`powerpoint_logs`** — логи событий интеграции с PowerPoint (начало/конец показа, смена слайдов)
